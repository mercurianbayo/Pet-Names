# 🐾 PetNamer

A fun, lightweight web app that generates random **male and female pet names** — with **blue confetti for male names** and **pink confetti for female names**.  
Built with **HTML, CSS, and JavaScript** — no frameworks, just pure fun!

---

# Features

-  Random **male** or **female** pet name generation  
- 🎉 Gender-based confetti animations (blue 💙 / pink 💖)  
-  One-click **copy to clipboard**  
-  Super fast and responsive  
-  Works entirely offline (no dependencies!)

---

## 🧱 Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling & layout  
- **JavaScript (Vanilla)** – Logic, interactivity, and confetti animation  
- **[canvas-confetti](https://www.npmjs.com/package/canvas-confetti)** – Lightweight confetti effect
